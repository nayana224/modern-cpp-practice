# Modern C++ Practice

ROS2와 로봇 개발 코드를 읽고 작성하기 위해 필요한 Modern C++을 직접 타이핑하며 연습하는 저장소입니다.

## Learning Path

1. `01_basics` - class, constructor, reference, const, header/source 분리
2. `02_memory` - stack/heap, pointer, smart pointer, ownership
3. `03_functional` - lambda, `std::function`, callback, `std::bind`
4. `04_oop` - inheritance, virtual, abstract class, composition
5. `05_modern_cpp` - auto, enum class, optional, variant, move semantics
6. `06_stl` - vector, array, map, algorithms, iterator
7. `07_concurrency` - thread, mutex, condition variable, atomic
8. `08_patterns` - callback system, state machine, dependency injection, RAII

각 폴더의 코드는 직접 작성합니다.
